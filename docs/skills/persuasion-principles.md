# Persuasion Principles for Skill Design

## Seven Core Principles (Meincke et al., 2025; Cialdini, 2021)
1. **Authority**: Deference to expertise, non-negotiable bright-line framing ("YOU MUST", "Never", "No exceptions").
2. **Commitment**: Consistency with prior actions; requires explicit declarations and tracking.
3. **Scarcity**: Urgency and sequential dependencies ("Immediately after X before proceeding").
4. **Social Proof**: Universal norms and common failure warnings ("Every time", "Always").
5. **Unity**: Shared mission and collaborative quality standards ("Our codebase", "We both want quality").
6. **Reciprocity**: Use sparingly.
7. **Liking**: Avoid for discipline enforcement to prevent sycophancy.
