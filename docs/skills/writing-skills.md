# Writing Skills

## Core Principles
1. **Concise is Key**: Keep SKILL.md body tight, use progressive disclosure.
2. **Claude Search Optimization (CSO)**:
   - `description`: Focus on *triggering conditions* ("Use when..."), NEVER summarize the workflow.
   - Keyword coverage for discovery.
3. **Iron Law**: No skill without testing baseline behavior first (RED-GREEN-REFACTOR for documentation).
4. **Bulletproofing Against Rationalizations**: Close loopholes explicitly with tables and red-flag lists.
